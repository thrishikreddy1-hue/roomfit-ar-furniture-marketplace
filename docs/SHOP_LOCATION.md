# Shop location

In **Seller → Edit shop profile → Add location**, paste your shop's Google Maps
share link and press **Save shop**. The public shop page then shows **View shop
location**, which opens Google Maps in a new browser tab or on the phone.

The link is optional. Clear it and save to remove the button. Accepted formats
include `https://maps.app.goo.gl/...`, `https://goo.gl/maps/...`,
`https://maps.google.com/...`, and `https://www.google.com/maps/...` (also
`google.co.in/maps`). Other domains, embedded credentials, unsafe schemes and
links longer than 2,048 characters are rejected. The server does not fetch links
or infer coordinates, and no paid Maps API key is needed.

The seller form no longer offers **Typical delivery time**. Existing stored
delivery details are preserved; editing the shop does not silently erase them.
